# chaos

The chaos agent that every tacplus fleet deploys by default (tacplus-dev/operator#18; Jody, 2026-11-01). It injects faults into its
**own fleet only** (pod kills by default; member, network and node faults as opt-in levels) and tags every fault, so a failure can be
matched to the fault behind it: one that recovered is logged and ignored, anything else is an incident. Turn it off per fleet in
`fleet.yaml`:

```yaml
chaos:
  enabled: false
```

It's a Rust service generated by tacplus. It never acts outside its fleet's namespaces, nor on `letsencrypt` or secret material.
